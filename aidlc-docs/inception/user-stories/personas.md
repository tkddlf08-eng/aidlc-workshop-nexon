# 사용자 페르소나 (User Personas)

---

## Persona 1: 고객 (Customer)

### 프로필
| 항목 | 내용 |
|------|------|
| **이름** | 김민수 (대표 페르소나) |
| **역할** | 매장 방문 고객 |
| **연령대** | 20~50대 (폭넓은 연령층) |
| **기술 수준** | 스마트폰/태블릿 기본 사용 가능 |
| **사용 환경** | 매장 내 테이블에 설치된 태블릿 |

### 목표 (Goals)
- 빠르고 간편하게 음식을 주문하고 싶다
- 메뉴를 천천히 둘러보며 선택하고 싶다
- 주문한 내역과 현재 상태를 확인하고 싶다
- 직원을 부르지 않고도 추가 주문을 하고 싶다

### 동기 (Motivations)
- 대기 시간 없이 즉시 주문 가능
- 메뉴 사진과 설명을 보고 선택할 수 있음
- 주문 실수를 줄일 수 있음 (장바구니에서 확인 후 확정)

### 불편사항 (Pain Points)
- 직원을 불러야 하는 번거로움
- 메뉴판이 작거나 정보가 부족한 경우
- 주문 후 얼마나 기다려야 하는지 모르는 불안감
- 복잡한 인터페이스나 로그인 절차

### 사용 시나리오
1. 테이블에 앉으면 태블릿이 자동으로 메뉴 화면을 표시
2. 카테고리별로 메뉴를 탐색하고 원하는 메뉴를 장바구니에 추가
3. 장바구니에서 수량 조절 후 주문 확정
4. 주문 내역에서 현재 주문 상태 확인
5. 추가 주문이 필요하면 같은 과정 반복

## Persona 2: 매장 관리자 (Admin)

### 프로필
| 항목 | 내용 |
|------|------|
| **이름** | 박서연 (대표 페르소나) |
| **역할** | 매장 사장님 / 운영 담당자 |
| **연령대** | 30~50대 |
| **기술 수준** | 기본적인 웹 서비스 사용 가능 |
| **사용 환경** | 카운터 PC 또는 태블릿 (브라우저) |

### 목표 (Goals)
- 들어오는 주문을 실시간으로 빠르게 확인하고 싶다
- 테이블별 주문 현황을 한눈에 파악하고 싶다
- 메뉴를 쉽게 등록/수정하고 싶다
- 테이블 회전율을 효율적으로 관리하고 싶다

### 동기 (Motivations)
- 인건비 절감 (주문 접수 인력 불필요)
- 주문 누락/실수 방지
- 매장 운영 효율성 증대
- 고객 대기 시간 감소로 만족도 향상

### 불편사항 (Pain Points)
- 바쁜 시간대에 주문을 놓치는 경우
- 테이블별 주문 현황 파악이 어려움
- 메뉴 변경 시 메뉴판 교체 비용/시간
- 이전 고객 주문과 현재 고객 주문이 섞이는 혼란

### 사용 시나리오
1. 영업 시작 시 관리자 로그인
2. 대시보드에서 테이블별 주문 현황 실시간 모니터링
3. 신규 주문 알림 확인 → 주문 상태 변경 (대기중 → 준비중 → 완료)
4. 고객 퇴장 시 테이블 이용 완료 처리
5. 필요 시 메뉴 추가/수정/삭제
6. 과거 주문 내역 확인 (매출 파악)
