# 사용자 스토리 (User Stories)

**분류 방식**: Persona-Based  
**세분화 수준**: Medium  
**Acceptance Criteria**: Checklist 스타일  
**우선순위**: MoSCoW (Must/Should/Could/Won't)

---

## 고객 스토리 (Customer Stories)

### Epic: 테이블 인증 (FR-C01)

#### US-C01: 태블릿 자동 로그인
**As a** 고객  
**I want** 테이블에 앉으면 별도 로그인 없이 바로 메뉴를 볼 수 있기를  
**So that** 대기 시간 없이 즉시 주문을 시작할 수 있다

**Priority**: Must

**Acceptance Criteria**:
- [ ] 태블릿 전원 켜짐/브라우저 접속 시 자동으로 메뉴 화면 표시
- [ ] 이전에 설정된 매장/테이블 정보로 자동 인증 수행
- [ ] 자동 로그인 실패 시 초기 설정 화면으로 이동
- [ ] 로그인 정보가 브라우저 로컬에 안전하게 저장됨

---

### Epic: 메뉴 조회 (FR-C02)

#### US-C03: 카테고리별 메뉴 탐색
**As a** 고객  
**I want** 카테고리별로 분류된 메뉴를 탐색할 수 있기를  
**So that** 원하는 종류의 음식을 빠르게 찾을 수 있다

**Priority**: Must

**Acceptance Criteria**:
- [ ] 메뉴 화면이 앱의 기본(홈) 화면으로 표시
- [ ] 카테고리 목록이 상단 또는 사이드에 표시
- [ ] 카테고리 선택 시 해당 카테고리의 메뉴만 필터링
- [ ] 카테고리 간 빠른 이동 가능 (탭 또는 스크롤)

---

#### US-C04: 메뉴 상세 정보 확인
**As a** 고객  
**I want** 메뉴의 이름, 가격, 설명, 이미지를 확인할 수 있기를  
**So that** 충분한 정보를 바탕으로 메뉴를 선택할 수 있다

**Priority**: Must

**Acceptance Criteria**:
- [ ] 카드 형태의 메뉴 레이아웃 표시
- [ ] 각 메뉴 카드에 메뉴명, 가격, 이미지 표시
- [ ] 메뉴 설명 표시 (카드 내 또는 상세 팝업)
- [ ] 터치 친화적 버튼 크기 (최소 44x44px)
- [ ] 이미지 로딩 실패 시 기본 플레이스홀더 표시

---

### Epic: 장바구니 (FR-C03)

#### US-C05: 메뉴를 장바구니에 추가
**As a** 고객  
**I want** 원하는 메뉴를 장바구니에 담을 수 있기를  
**So that** 여러 메뉴를 모아서 한 번에 주문할 수 있다

**Priority**: Must

**Acceptance Criteria**:
- [ ] 메뉴 카드에서 추가 버튼 클릭 시 장바구니에 담김
- [ ] 이미 담긴 메뉴 추가 시 수량 증가
- [ ] 장바구니 아이콘에 담긴 항목 수 표시
- [ ] 추가 시 시각적 피드백 제공 (토스트 또는 애니메이션)

---

#### US-C06: 장바구니 수정 및 관리
**As a** 고객  
**I want** 장바구니에서 수량을 조절하거나 메뉴를 삭제할 수 있기를  
**So that** 주문 전에 원하는 대로 조정할 수 있다

**Priority**: Must

**Acceptance Criteria**:
- [ ] 수량 증가/감소 버튼 제공
- [ ] 수량 0 또는 삭제 버튼으로 항목 제거
- [ ] 총 금액이 실시간으로 재계산되어 표시
- [ ] 장바구니 전체 비우기 기능 제공
- [ ] 페이지 새로고침 후에도 장바구니 내용 유지 (로컬 저장)

---

### Epic: 주문 생성 (FR-C04)

#### US-C07: 주문 확정
**As a** 고객  
**I want** 장바구니 내용을 확인하고 주문을 확정할 수 있기를  
**So that** 실수 없이 원하는 메뉴를 주문할 수 있다

**Priority**: Must

**Acceptance Criteria**:
- [ ] 주문 확정 전 주문 내역 최종 확인 화면 표시
- [ ] 주문 확정 버튼 제공
- [ ] 활성 테이블 세션이 없으면 새 세션 자동 생성
- [ ] 주문 성공 시 주문 번호 표시
- [ ] 주문 성공 시 장바구니 자동 비우기
- [ ] 5초 후 메뉴 화면으로 자동 리다이렉트
- [ ] 주문 실패 시 에러 메시지 표시
- [ ] 주문 실패 시 장바구니 내용 유지

---

#### US-C08: 추가 주문
**As a** 고객  
**I want** 이전 주문 후에도 추가로 메뉴를 주문할 수 있기를  
**So that** 식사 중 필요한 메뉴를 자유롭게 추가할 수 있다

**Priority**: Must

**Acceptance Criteria**:
- [ ] 주문 완료 후 메뉴 화면으로 돌아가면 새로운 장바구니로 시작
- [ ] 추가 주문이 같은 테이블 세션에 연결됨
- [ ] 이전 주문과 독립적으로 새 주문 생성 가능

---

### Epic: 주문 내역 조회 (FR-C05)

#### US-C09: 현재 세션 주문 내역 확인
**As a** 고객  
**I want** 현재 식사 세션의 주문 내역을 확인할 수 있기를  
**So that** 무엇을 주문했는지, 현재 상태가 어떤지 알 수 있다

**Priority**: Must

**Acceptance Criteria**:
- [ ] 주문 내역 화면에서 현재 세션의 주문만 표시
- [ ] 주문 시간 순 정렬
- [ ] 각 주문별: 주문 번호, 시각, 메뉴/수량, 금액, 상태 표시
- [ ] 주문 상태 표시 (대기중/준비중/완료)
- [ ] 이전 세션(이용 완료된) 주문은 표시하지 않음

---

#### US-C10: 주문 목록 페이지네이션
**As a** 고객  
**I want** 주문이 많을 때 페이지 단위로 나눠서 볼 수 있기를  
**So that** 화면이 과도하게 길어지지 않고 쾌적하게 탐색할 수 있다

**Priority**: Should

**Acceptance Criteria**:
- [ ] 주문 목록이 일정 개수 이상이면 페이지네이션 또는 무한 스크롤 적용
- [ ] 페이지 이동 시 부드러운 전환

---

## 관리자 스토리 (Admin Stories)

### Epic: 매장 인증 (FR-A01)

#### US-A01: 관리자 로그인
**As a** 관리자  
**I want** 매장 식별자와 계정 정보로 로그인할 수 있기를  
**So that** 매장 관리 시스템에 안전하게 접근할 수 있다

**Priority**: Must

**Acceptance Criteria**:
- [ ] 매장 식별자, 사용자명, 비밀번호 입력 폼 제공
- [ ] 로그인 성공 시 대시보드로 이동
- [ ] 로그인 실패 시 에러 메시지 표시
- [ ] 로그인 시도 제한 (연속 실패 시 일시 차단)
- [ ] JWT 토큰 발급 및 로컬 저장

---

#### US-A02: 세션 유지 및 자동 로그아웃
**As a** 관리자  
**I want** 16시간 동안 세션이 유지되고 이후 자동 로그아웃되기를  
**So that** 영업 시간 동안 재로그인 없이 사용하면서도 보안이 유지된다

**Priority**: Must

**Acceptance Criteria**:
- [ ] 로그인 후 16시간 동안 세션 유지
- [ ] 브라우저 새로고침 시에도 세션 유지
- [ ] 16시간 경과 시 자동 로그아웃 및 로그인 화면 이동
- [ ] 로그아웃 시 토큰 삭제

---

### Epic: 실시간 주문 모니터링 (FR-A02)

#### US-A03: 테이블별 주문 대시보드
**As a** 관리자  
**I want** 모든 테이블의 주문 현황을 그리드 형태로 한눈에 볼 수 있기를  
**So that** 매장 전체 상황을 빠르게 파악할 수 있다

**Priority**: Must

**Acceptance Criteria**:
- [ ] 테이블별 카드 형태의 그리드 레이아웃 표시
- [ ] 각 테이블 카드에 테이블 번호, 총 주문액 표시
- [ ] 각 테이블 카드에 최신 주문 미리보기 (n개)
- [ ] 테이블별 필터링 기능 제공

---

#### US-A04: 실시간 주문 알림
**As a** 관리자  
**I want** 새로운 주문이 들어오면 실시간으로 화면에 반영되기를  
**So that** 주문을 놓치지 않고 즉시 대응할 수 있다

**Priority**: Must

**Acceptance Criteria**:
- [ ] SSE를 통해 신규 주문 실시간 수신
- [ ] 신규 주문 발생 시 2초 이내 화면 반영
- [ ] 신규 주문 시각적 강조 (색상 변경 또는 애니메이션)
- [ ] 연결 끊김 시 자동 재연결

---

#### US-A05: 주문 상태 변경
**As a** 관리자  
**I want** 주문 상태를 대기중 → 준비중 → 완료로 변경할 수 있기를  
**So that** 주문 처리 진행 상황을 관리하고 고객에게 알릴 수 있다

**Priority**: Must

**Acceptance Criteria**:
- [ ] 주문 카드에서 상태 변경 버튼 제공
- [ ] 대기중 → 준비중 → 완료 순서로만 변경 가능 (단방향)
- [ ] 상태 변경 즉시 화면 반영
- [ ] 상태 변경 성공/실패 피드백 제공

---

#### US-A06: 주문 상세 보기
**As a** 관리자  
**I want** 주문 카드를 클릭하면 전체 메뉴 목록을 상세히 볼 수 있기를  
**So that** 주문 내용을 정확히 확인할 수 있다

**Priority**: Must

**Acceptance Criteria**:
- [ ] 주문 카드 클릭 시 상세 팝업/패널 표시
- [ ] 주문 번호, 시각, 테이블 번호 표시
- [ ] 전체 메뉴 목록 (메뉴명, 수량, 단가) 표시
- [ ] 총 금액 표시
- [ ] 닫기 버튼으로 대시보드 복귀

---

### Epic: 테이블 관리 (FR-A03)

#### US-A07: 테이블 초기 설정 (태블릿)
**As a** 관리자  
**I want** 태블릿에 매장/테이블 정보를 1회 설정할 수 있기를  
**So that** 이후 고객이 별도 설정 없이 사용할 수 있다

**Priority**: Must

**Acceptance Criteria**:
- [ ] 매장 식별자 입력 필드 제공
- [ ] 테이블 번호 입력 필드 제공
- [ ] 테이블 비밀번호 입력 필드 제공
- [ ] 설정 완료 시 로그인 정보 로컬 저장
- [ ] 설정 성공 후 메뉴 화면으로 자동 이동

---

#### US-A08: 주문 삭제 (직권 수정)
**As a** 관리자  
**I want** 잘못된 주문을 삭제할 수 있기를  
**So that** 고객의 실수나 시스템 오류를 즉시 정정할 수 있다

**Priority**: Must

**Acceptance Criteria**:
- [ ] 주문별 삭제 버튼 제공
- [ ] 삭제 전 확인 팝업 표시
- [ ] 삭제 후 테이블 총 주문액 자동 재계산
- [ ] 삭제 성공/실패 피드백 제공

---

#### US-A09: 테이블 이용 완료 처리
**As a** 관리자  
**I want** 고객 퇴장 시 테이블을 이용 완료 처리할 수 있기를  
**So that** 다음 고객이 깨끗한 상태에서 시작할 수 있다

**Priority**: Must

**Acceptance Criteria**:
- [ ] 테이블별 "이용 완료" 버튼 제공
- [ ] 이용 완료 전 확인 팝업 표시
- [ ] 이용 완료 시 해당 세션 주문 내역이 과거 이력으로 이동 (is_archived = true)
- [ ] 이용 완료 시 테이블 현재 주문 목록 및 총 주문액 0으로 리셋
- [ ] 성공/실패 피드백 제공

---

#### US-A10: 과거 주문 내역 조회
**As a** 관리자  
**I want** 테이블별 과거 주문 내역을 조회할 수 있기를  
**So that** 이전 매출과 주문 이력을 확인할 수 있다

**Priority**: Should

**Acceptance Criteria**:
- [ ] "과거 내역" 버튼 제공
- [ ] 테이블별 과거 주문 목록 표시 (시간 역순)
- [ ] 각 주문: 주문 번호, 시각, 메뉴 목록, 총 금액, 이용 완료 시각 표시
- [ ] 날짜 필터링 기능 제공
- [ ] "닫기" 버튼으로 대시보드 복귀

---

### Epic: 메뉴 관리 (FR-A04)

#### US-A11: 카테고리 관리
**As a** 관리자  
**I want** 메뉴 카테고리를 추가/수정/삭제할 수 있기를  
**So that** 메뉴를 체계적으로 분류하여 고객이 쉽게 탐색할 수 있다

**Priority**: Must

**Acceptance Criteria**:
- [ ] 카테고리 목록 조회 기능
- [ ] 새 카테고리 추가 (카테고리명 입력)
- [ ] 카테고리명 수정 기능
- [ ] 카테고리 삭제 기능 (해당 카테고리에 메뉴가 없을 때만)
- [ ] 카테고리 노출 순서 조정
- [ ] 중복 카테고리명 검증

---

#### US-A12: 메뉴 등록
**As a** 관리자  
**I want** 새로운 메뉴를 등록할 수 있기를  
**So that** 매장의 메뉴를 디지털로 관리할 수 있다

**Priority**: Must

**Acceptance Criteria**:
- [ ] 메뉴 등록 폼 제공 (메뉴명, 가격, 설명, 카테고리, 이미지)
- [ ] 기존 카테고리 목록에서 선택
- [ ] 이미지 파일 업로드 → S3 저장
- [ ] 필수 필드 검증 (메뉴명, 가격, 카테고리)
- [ ] 가격 범위 검증 (0 이상)
- [ ] 등록 성공/실패 피드백

---

#### US-A13: 메뉴 수정 및 삭제
**As a** 관리자  
**I want** 기존 메뉴를 수정하거나 삭제할 수 있기를  
**So that** 메뉴 변경 사항을 즉시 반영할 수 있다

**Priority**: Must

**Acceptance Criteria**:
- [ ] 메뉴별 수정/삭제 버튼 제공
- [ ] 수정 시 기존 정보가 폼에 미리 채워짐
- [ ] 이미지 변경 가능
- [ ] 삭제 전 확인 팝업 표시
- [ ] 수정/삭제 성공/실패 피드백

---

#### US-A14: 메뉴 조회 및 순서 관리
**As a** 관리자  
**I want** 카테고리별로 메뉴를 조회하고 노출 순서를 조정할 수 있기를  
**So that** 고객에게 보여지는 메뉴 순서를 원하는 대로 설정할 수 있다

**Priority**: Should

**Acceptance Criteria**:
- [ ] 카테고리별 메뉴 목록 조회
- [ ] 드래그앤드롭 또는 순서 변경 버튼으로 노출 순서 조정
- [ ] 순서 변경 즉시 저장
- [ ] 변경된 순서가 고객 화면에 반영
