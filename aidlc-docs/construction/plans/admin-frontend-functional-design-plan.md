# Admin Frontend - Functional Design Plan

## 개요
Unit 3 (Admin Frontend)의 상세 비즈니스 로직 및 UI 컴포넌트 설계를 수행합니다.

## Unit 3 컨텍스트
- **기술 스택**: React, TypeScript, Zustand, SSE Client
- **담당 스토리**: 14개 (Must 12 / Should 2)
- **핵심 기능**: 관리자 로그인, 실시간 주문 대시보드, 테이블 관리, 메뉴/카테고리 관리
